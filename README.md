# Инсайд: комикс об обновлениях

Лента с комиксами-видео. Открывается файлом `index.html`.

## Как добавить видео или GIF
1. Положите файл в папку `media` (например `media/02-rashody.mp4`).
2. В `index.html` найдите блок `const MEDIA = {` и допишите строку:
   `2: "media/02-rashody.mp4",` — число слева это номер поста в ленте.
3. Сохраните изменения (Commit). Сайт обновится через минуту-две.

## Режим примерки
Добавьте `?edit` в конец адреса сайта — появятся кнопки загрузки,
и файлы можно перетаскивать прямо в посты. Это видно только вам,
в вашем браузере; посетители видят файлы из папки `media`.
